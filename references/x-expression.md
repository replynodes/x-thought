# X Expression

Write a post, not a miniature LinkedIn post.

- Start with the observation or claim when possible. Do not default to a hook.
- Use the shortest form that preserves the thought. One to four short paragraphs is usually enough.
- Include a source link only when it adds credibility or invites the reader to inspect the evidence.
- Keep uncertainty visible when evidence is incomplete.
- Avoid forced lessons, "not X, but Y" reversals, three-item lists, empty rhetorical questions, generic superlatives, em-dash-heavy prose, and calls to like/repost/comment.
- Do not add hashtags by default.
- Do not turn a single thought into a thread unless the user explicitly asks or the idea needs multiple independently useful claims.

The post should be legible to a fast-scrolling reader but should not sacrifice precision for virality.
